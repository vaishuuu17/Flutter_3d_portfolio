## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/vaishuuu17/Flutter_3d_portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Flutter_3d_portfolio
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

For Chrome:

```bash
flutter run -d chrome
```

For Android:

```bash
flutter run
```
